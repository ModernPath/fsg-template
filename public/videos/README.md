# Videos Folder

## Current Implementation

The site uses:

1. **Animated Ocean Background** - Hero section has beautiful CSS-animated ocean with waves, light rays, and particles
2. **Video Preview Cards** - Gallery shows images with play buttons that link to YouTube

## Why Not Actual Video Files?

- Video files are large (10-50MB each)
- Slow to load and can cause performance issues
- Better UX to link to YouTube/Vimeo for actual video playback
- Animated background provides beautiful "moving" effect without video overhead

## To Add Real Videos Later

If you want to add actual embedded videos:

1. Upload your videos to YouTube or Vimeo
2. Use their embed codes
3. Or download and place MP4 files here:
   - `boat-dolphins-bg.mp4` (for hero background, max 5MB recommended)
   - `dolphins.mp4` 
   - `sunset.mp4`
   - `tour.mp4`

## Best Practice

Current implementation (animated background + YouTube links) is actually BETTER than embedded videos because:
- Faster page load
- Better mobile performance  
- Professional video hosting
- Analytics from YouTube
- No bandwidth costs
